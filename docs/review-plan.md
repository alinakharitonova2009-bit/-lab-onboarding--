## 3. Критерии проверки (чек-лист)

### 3.1. Функциональная корректность
- [ ] Корректный расчет итоговой суммы с учетом всех примененных скидок.
- [ ] Правильная обработка ошибок при взаимодействии с бэкенд-API (например, если товар закончился).

### 3.2. Безопасность / Надежность
- [ ] Отсутствие передачи чувствительных данных (токенов, номеров карт) в открытом виде или в URL.
- [ ] Защита от XSS-уязвимостей при выводе пользовательских данных.

### 3.3. Производительность
- [ ] Компонент не вызывает лишних повторных рендеров (использование memo/useCallback при необходимости).
- [ ] Время отрисовки компонента при 100+ товарах не превышает 100 мс.

### 3.4. Читаемость и стиль
- [ ] Строгое соблюдение типизации TypeScript (отсутствие типов `any`).
- [ ] Отсутствие магических чисел и строк, вынос констант.
